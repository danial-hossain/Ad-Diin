## 🔹 Project Overview

### 📖 Description
Ad-Diin is a mosque management and community engagement platform designed to digitize and streamline mosque operations such as prayer scheduling, donations, zakat management, events, and religious activities. The platform also integrates **Diin AI**, an AI-powered Islamic learning assistant that helps users learn Islamic topics based on the **Qur’an and Hadith** in a respectful and educational manner.

---

## 🎯 Objective

The objectives of this project are to:
- Digitize mosque management processes
- Improve transparency in donations and zakat
- Enhance community engagement
- Provide AI-assisted Islamic learning support

---

## 🎯 Target Audience
- Mosque committees and administrators
- Local Muslim community members
- Donors and zakat contributors
- Students and learners seeking Islamic knowledge

## 🚀 Project Features

### Core Features
- Public prayer time display (Azan & Jamaat)
- Mosque activities and event management
- Milad & Mahfil booking system
- Zakat management and calculation
- Donation management with categorized donation types
- Community announcements

---

### AI Integration (Exclusive Feature)

**Diin AI**
- AI-powered Islamic learning assistant
- Educational guidance based on Qur’an & Hadith
- Helps users understand:
  - Prayer
  - Zakat
  - Fasting
  - Basic Islamic teachings

---

### Authentication
- JWT-based authentication
- Role-based login:
  - User
  - Admin

---

### Admin Dashboard
- User statistics
- Donation & zakat summaries
- Prayer time management
- Activity & event CRUD operations
- Milad request management
- Donation types management
